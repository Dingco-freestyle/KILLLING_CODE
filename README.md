## 📜 스터디 규칙 (Rule)

### 📅 진행 방식
* **매일 1일 1문제** 해결을 원칙으로 합니다.
* 매일 각자 원하는 문제를 골라 풀고 주차별 리드미에 업데이트합니다.

### ⏰ 기한 및 벌금
* **당일 문제 업로드 기한:** 매일 밤 23시 59분까지 Pull Request(PR) 제출 완료.
* **벌금 제도:** 기한 내에 풀이 코드를 올리지 못하거나, 도전 여부를 남기지 않을 시 **건당 1,000원**의 벌금이 부과됩니다.

### 💬 코드 리뷰 규칙
* 서로의 브랜치에서 생성된 PR에 대해 최소 **1명 이상의 스터디원에게 승인(Approve)**을 받아야 메인(main) 브랜치로 머지할 수 있습니다.
